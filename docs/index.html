↳ IAM role

Grants the app access to Claude and AWS web search. No personal access keys on the server.

↳ Persistent disk

Encrypted EBS storage. SQLite usage counters survive app restarts and server reboots.

↳ Operations

Systemd starts and restarts the app. Systems Manager provides administration without SSH.

* Origin connection: browser traffic uses HTTPS to CloudFront. CloudFront connects to Nginx over HTTP, restricted by a CloudFront-only security group and a secret origin header. This deployment does not use end-to-end TLS to EC2.

Progress follows the work.

The app streams actual planner, search, and writer updates. This architecture page is an interactive explanation; selecting cards does not run research or call paid APIs.

Keep the providers independent.

Separate folders, dependencies, and environment settings preserve the GPT implementation alongside AWS. Both can be packaged with the root Dockerfile.

Public preview has limits.

The AWS deployment allows 3 attempts per visitor address daily, 50 globally daily, and 1,000 monthly. Failed attempts count. Public email delivery is disabled.
